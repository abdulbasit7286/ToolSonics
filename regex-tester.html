Regex Cheatsheet

Character Classes
. Any character except newline
\w \d \s Word, digit, whitespace
\W \D \S Not word, digit, whitespace
[abc] Any of a, b, or c
[^abc] Not a, b, or c
Quantifiers
a* 0 or more
a+ 1 or more
a? 0 or 1
a{3} Exactly 3
a{3,} 3 or more
Anchors
^abc Start of string
abc$ End of string
\b \B Word boundary, Not boundary
Groups & Lookaround
(abc) Capture group
(?:abc) Non-capture group
(?=abc) Positive lookahead
(?!abc) Negative lookahead
